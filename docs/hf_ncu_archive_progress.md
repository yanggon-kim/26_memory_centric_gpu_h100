# H200 Nsight Compute report archive

Updated: 2026-10-21

The 262 H200 `.ncu-rep` files were uploaded to the private Hugging Face dataset repository [`yang-gon/h200-ncu-reports`](https://huggingface.co/datasets/yang-gon/h200-ncu-reports). The source reports total 5,238,202,215 bytes (about 4.878 GiB). The upload client reported 459 MB transferred, consistent with deduplication in the Hub's storage backend.

The latest upload commit shown by the CLI was [`fc4d46f`](https://huggingface.co/datasets/yang-gon/h200-ncu-reports/commit/fc4d46fc93225e16aaa3c8b3e64393583a34d57f).
